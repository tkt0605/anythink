# Anythink UI デザイン仕様

[UI_design.md](./UI_design.md) に基づく、シンプルな画面構成です。

## 共通

- 背景は白、本文は濃い文字、操作に使う色は落ち着いた青の一色に絞る。
- コンテンツ幅は最大 700px。見出しと余白で内容を分け、影や装飾的な下線は使わない。
- ヘッダーはロゴ、「投稿を見る」、認証操作だけにする。スマートフォンでは新規登録のリンクをログイン画面内に置く。
- ボタン・リンク・入力欄にはキーボードのフォーカスを明示する。動きを減らす設定を尊重する。

## 入口

「考えを書いて、話す。」という見出し、短い説明、「投稿を見る」ボタンだけを置く。

## 投稿一覧

ページ上部の大きな見出しは置かない。投稿欄と一覧を縦に並べる。未ログイン時は投稿欄にログインへのリンクを置く。各投稿は本文と「会話を見る」だけを表示する。読み込み中・空・エラーは短い文章で伝える。

## 投稿の詳細

ページ上部の大きな見出しは置かない。元の考え、会話、まとめ、関連する考えをこの順に並べる。会話では返信を時系列で読み、ログイン後に返信できる。まとめの編集操作は作成者だけに表示する。

## 認証

ログインと新規登録は、中央に一列のフォームを置く。見えるラベル、送信中の文言、エラーや確認メールの案内を維持する。両画面を相互に移動できるリンクをフォームの下に置く。

## 色とレスポンシブ

本文 `#26333f`、補助文字 `#4e5d68`、強調 `#205d8f`、背景 `#ffffff`、境界線 `#d9e2e9`。主ボタンの白文字と青色の背景は約 6.9:1 のコントラスト比を確保する。600px 以下では左右の余白を狭くし、投稿案内と会話案内を縦に並べる。
