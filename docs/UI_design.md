#　UI/UXデザインの案

# Role/Instruction
あなたは世界最高峰のUI/UXデザイナーおよびフロントエンドエンジニアです。
以下の要件を満たす、洗練されたWebアプリのUI/UXデザイン案および画面設計を作成してください。

# Context
- アプリ名: AnyThink - 思考・接続・会話・集合知へ成長する、AIネイティブな次世代のSNSサービス。
- プロダクトの目的: AIは「しゃべる主役」ではなく、理解する、つなぐ、整理するための静かな知性として利用する。
- ターゲットユーザー: Z世代、20~30代、ビジネスマン、田舎に住むご老人にも。誰にでもわかるようなデザイン
- アプリの雰囲気・世界観: クリーンでシンプル。洗練されたデザインを構築。
- テーマカラー: ここは一緒に詰めていきたい。

# Requirements
1. レイアウト構成
- 一緒に詰めていきたい。
2. 機能要件
- ここも一緒に詰めていきたい。
- モバイル表示時（レスポンシブ）にも崩れないレイアウト
3. UX・アクセシビリティ
- 誰にでもわかるようにしたくてはいけない。一瞬でわかるようなUXに。
- WCAG基準に適合するコントラスト比の確保
- ホバーアニメーションやローディング時の配慮
4. 出力形式
- セクションごとのデザイン仕様（UI要素、配置）を日本語で詳細に解説
- 可能であれば、Tailwind CSSやHTMLを用いた実装コードのサンプルを提示
